# Note Style v2.0

このサイトのNotesは、講義録や教科書ではなく、理解の過程を残す研究・学習ノートとして書く。

## 基本の声

- 読者へ順番に教える語り口より、観察・式・解釈を直接置く。
- 「このノートでは〜を見る／学ぶ」「まず〜」「次に〜」のような授業進行は原則使わない。
- 「ここで大事なのは」「覚えておくべき」は避け、何が重要かを内容そのものから書く。
- 一人称は、独自の見方や判断を示すときだけ使う。毎節の進行役にはしない。
- 文体は教科書より少し柔らかく、会話文よりは圧縮する。

## 導入

導入は次のどれかから始める。

1. 既存の描像に残る違和感。
2. 比較したい二つの構造。
3. 具体的な式や現象から出る疑問。

その後にモデルを置き、ノート全体の中心となる解釈を一度だけ示す。

避けたい形：

> このノートではAを説明し、次にBを見て、最後にCを考える。

好む形：

> Aだけを見るとBは同じ現象に見える。しかしCを入れると両者は分かれる。

## 見出し

見出しは「手順」より「内容」を表す。

- `まず周期を探してみる` → `周期条件が作る制約`
- `次に外場を入れる` → `外場が絶対方向を持ち込む`
- `何を見ればよいか` → `判別に使う量`

## 節間の接続

節の末尾で次節を予告しすぎない。必要なら、現在の式から自然に残る未解決点を一文だけ置く。

- `次に〜を見よう` ではなく `この近似では〜がまだ決まらない。`
- `ここまで分かったので〜へ進む` ではなく `残る自由度は〜である。`

## 数式との関係

- 式を出した直後に同じ内容を言い換えるだけの説明を重ねない。
- 導出は、式変形そのものが物理的・数学的構造を示す場合に残す。
- 中心式は display math、短い条件や定義は inline math を優先する。

## 終わり方

「まとめ」より、そのノートで得られた見方を短く固定する。必要なら「残る疑問」「接続」として次の問題を置く。

## 目安

一つの節を読んだとき、教師が順番を案内している感じではなく、ノートを書いた人の思考の断面が見える状態を目指す。


## 用語

- 日本語で定訳が定着している専門語は日本語を優先する。
- 英語を残すのは、固有名、記号との対応を保ちたい語、訳語が分野内で揺れる語に限る。
- 初出で対応関係が有用な場合は「転送行列 (transfer matrix)」のように英語を併記してよいが、以降は日本語を使う。
- 例：state space → 状態空間、symmetry → 対称性、interaction range → 相互作用範囲、spatial organization → 空間構造、transfer matrix → 転送行列、transfer spectrum → 転送スペクトル、response → 応答、Markov chain → マルコフ連鎖、phase diffusion → 位相拡散。
- chirality は「カイラリティ」のように日本語表記へ寄せる。tilted operator など訳語が十分に定着していない語は、無理に意訳せず英語または日英併記を許す。

## 改訂時の編集原則

- 正確性、論理、情報密度、日本語の自然さの順に点検する。簡潔さのために成立条件や導出を省かない。
- 事実、既存理論、独自の解釈、仮説を区別し、根拠に応じて断定の強さを調整する。
- 原典と数式を確認する。未確認の出典や結果を補って作らない。
- 一段落に一つの論点を持たせ、論理的な接続を優先する。段落末の形式的な要約は不要。
- 抽象的な重要性の強調、人工的な驚き、読者への不要な問いかけ、機械的な対比、英語と日本語の不必要な混在を避ける。具体的な関係や条件を記述する。
- 記事の長さや節数を統一しない。数式、表、図は論述に必要な場合に用いる。
- 記事は同じ対象ではなく同じ問いを基準に統合する。共通理論は独立した記事にまとめ、個別模型の固有の導出・結果・解釈は残す。
- 改稿前に記事の主張、依存する知識、固有の内容、重複部分、出典を確認する。構成を再設計してから文章を書く。
- 統合・分割に伴う旧URL、内部リンク、図版参照を検証する。更新日は実際の改訂時に更新する。
- 研究ノートとして未解決の問いを残すことは許容するが、確認されていない内容を結論として扱わない。
