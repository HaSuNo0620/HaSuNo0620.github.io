# Note Style v1.0

このサイトのNotesは、講義録や教科書ではなく、理解の過程を残す研究・学習ノートとして書く。

## 基本の声

- 読者へ順番に教える語り口より、観察・式・解釈を直接置く。
- 「このノートでは〜を見る／学ぶ」「まず〜」「次に〜」のような授業進行は原則使わない。
- 「ここで大事なのは」「覚えておくべき」は避け、何が重要かを内容そのものから書く。
- 一人称は、独自の見方や判断を示すときだけ使う。毎節の進行役にはしない。
- 文体は教科書より少し柔らかく、会話文よりは圧縮する。

## 導入

導入は次のどれかから始める。

1. 既存の描像に残る違和感。
2. 比較したい二つの構造。
3. 具体的な式や現象から出る疑問。

その後にモデルを置き、ノート全体の中心となる解釈を一度だけ示す。

避けたい形：

> このノートではAを説明し、次にBを見て、最後にCを考える。

好む形：

> Aだけを見るとBは同じ現象に見える。しかしCを入れると両者は分かれる。

## 見出し

見出しは「手順」より「内容」を表す。

- `まず周期を探してみる` → `周期条件が作る制約`
- `次に外場を入れる` → `外場が絶対方向を持ち込む`
- `何を見ればよいか` → `判別に使う量`

## 節間の接続

節の末尾で次節を予告しすぎない。必要なら、現在の式から自然に残る未解決点を一文だけ置く。

- `次に〜を見よう` ではなく `この近似では〜がまだ決まらない。`
- `ここまで分かったので〜へ進む` ではなく `残る自由度は〜である。`

## 数式との関係

- 式を出した直後に同じ内容を言い換えるだけの説明を重ねない。
- 導出は、式変形そのものが物理的・数学的構造を示す場合に残す。
- 中心式は display math、短い条件や定義は inline math を優先する。

## 終わり方

「まとめ」より、そのノートで得られた見方を短く固定する。必要なら「残る疑問」「接続」として次の問題を置く。

## 目安

一つの節を読んだとき、教師が順番を案内している感じではなく、ノートを書いた人の思考の断面が見える状態を目指す。
