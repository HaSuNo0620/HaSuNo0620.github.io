# Prose Style v1.0

Notes は講義録ではなく、自分の理解・計算・解釈を後から辿るための研究・学習ノートとして書く。

- 読者への手順指示を減らす。
- 「まず」「次に」「ここで重要なのは」「覚えておきたい」を多用しない。
- 式の前後では、操作の指示ではなく式の意味と自然さを書く。
- 「考えてみよう」より「考える」、「見てみる」より「見る／現れる」を使う。
- 問いかけはノートの中心問題を切り出す場合に限定する。
- 節末の「次へ進む」は、ノート間の接続として必要な場合だけ残す。
- 文体は常体。教科書と完全な私的メモの中間を目指す。
- 数式、図、技術的主張は保ち、語り口だけを調整する。

基本の流れは、現象・違和感 → 最小モデル → 計算 → 解釈 → 残る疑問、とする。
