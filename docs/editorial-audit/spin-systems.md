## 共通理論

零外場の有限範囲cosine模型の増分表示、開鎖と周期境界の制約、熱力学極限、転送状態の構成、Perron固有ベクトルによるマルコフ核の規格化、傾斜転送作用素、連結相関と線形応答、スペクトルの振幅と選択則を導出する。マルコフ次数と相関長を区別。R=1の空の履歴は独立増分として別扱い。重複固有値・Jordanブロックでは単純な指数和が成立しないことを明記。有限範囲を有限温度相転移と混同しない。

## 個別の要検証事項

- Ising R1: 開鎖と周期鎖の壁パリティ制約、反強磁性の符号、相互情報量の対数底、情報と仕事の条件。一般範囲の説明は共通記事へ。
- Ising R2: 固有値と判別式の導出、重根での多項式因子、生成関数の分子分母を明示。応答最大は端点を含め判定。Lifshitz-like line の式と漸近、図を独立検算。Fisher–Widomとの類似は機構の差と次元依存の代数因子を明示。
- Ising Rn / 範囲比較: 「R-1ステップ相関」を「最大R-1次のマルコフ依存」に修正。観測量に寄与する固有値と縮退を区別。
- Clock R1 / 最近接比較: 強磁性条件を明記。低温Bessel近似の有効範囲、q=2の励起縮退、有限環の制約。極限の非可換性は xi_q/xi_XY に対して明記。奇数qでは一般に二次磁化応答が許される（q=3独立スピンで確認）。qを状態数と波数の両方に使わない。
- Clock R2 / Rn / 比較: 一様ねじれ最小化は制限された変分問題。q=2,J2=-J1 の++--が反例。有限状態の最小平均重み閉路による基底状態探索を導入。反転で異なるカイラリティは角度0,piを除く。有限温度の相関と基底状態ピッチを区別。
- XY R1: 角度を持ち上げた実数増分の分散と円周上の角度を区別。測度 dtheta と dtheta/(2pi) の自由エネルギー規約を明記。低温高調波展開の条件。
- XY R2: 一様螺旋の大域最小性を説明。勾配展開、キンクエネルギー、調和近似を再検算。テレグラフ過程は独立ノイズ等を仮定した有効模型であり、振動消失・ピーク分岐の条件を区別。Q_peakの式は実根がある場合のみ、他は0。正負ローレンツ型ピークの重なりに注意。Fourier基底の核行列要素は測度による2pi係数を照合。数値表の格子収束を再現。回転外場とカイラリティ共役場を区別。
- XY Rn: 履歴空間の次元はR-1。局所極小と大域基底状態、熱的なセクターの重みを区別。スピン相関は傾斜作用素を使う。
- 周期Ising: 周期境界の制約、単位胞のBloch波数と内部Fourier成分を区別。AABBの解析式を転送行列の微分と独立検算。応答チャネルの優劣は限定した外場部分空間での比較。混合角は象限と縮退を扱う。
- XXZ: J>0、零温度・零磁場の条件、Delta=-1境界、Delta=1の対数補正、磁場下のLuttingerパラメータの変化、飽和磁場の適用範囲。正のホッピング規約では占有領域がBrillouin zone端側になるため k_F=pi n の記述はゲージ変換または2k_Fの同値性と整合させる。原典・標準文献を補う。
