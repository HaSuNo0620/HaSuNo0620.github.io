# Diagram Style

このサイトの模式図・物理イメージ図の共通ルール。

## 1. 役割

図は数式の装飾ではなく、数式が表す物理像を先に見せるために使う。原則として 1 図 1 メッセージとし、図は次の3種に分ける。

- **構造図**: 変数・状態・対応関係を説明する。
- **現象図**: 物理的な変化や機構を見せる。
- **対応図**: 実空間と Fourier 空間など、二つの表現の対応を示す。

## 2. 言語

図中の語は、日本語で自然な専門語がある場合は日本語を優先する。

例:

- free domain walls → 自由なドメイン壁
- interacting domain walls → 相互作用するドメイン壁
- monotone correlations → 単調減衰する相関
- oscillatory tail → 遠方で振動する相関
- finite-q response → 有限波数応答

固有名や定着した専門語は英語を残してよい。例: Stephenson disorder line, Fisher–Widom line, Ornstein–Zernike。

図中に長文を置かない。短いラベルと式に限定し、解釈はキャプションへ送る。

## 3. 配色

サイト本体と同じ色を使う。

- paper: `#f3efe6`
- paper-2: `#ebe5d9`
- ink: `#171714`
- muted: `#716d64`
- line: `#cbc3b5`
- accent: `#5866e9`
- accent-soft: `#dfe2ff`
- green: `#39705a`

原則:

- 背景は透明、または paper / paper-2。
- 大面積の青・緑ベタ塗りは避ける。
- accent blue は主対象・現在注目しているモード。
- green は比較対象・補助構造・第二の相互作用。
- 通常文字・輪郭・軸は theme-aware ink。
- 黒色を固定値として使わない。

## 4. 配置の視覚文法

- 左 → 右: 変化、因果、変換。
- 上 → 下: スケール、階層、別表現。
- 左右2列: 対応関係・比較。
- 3段: パラメータ変化に伴う現象の進行。

## 5. 幾何学的一貫性

物理量と図形位置を別々に手配置しない。

特にスピン鎖では、スピン配列 `s_i` を唯一の source of truth とする。

1. `x_i = x_0 + i Δx` からスピン位置を生成する。
2. `s_i != s_{i+1}` なら壁位置を `x_wall = (x_i + x_{i+1})/2` とする。
3. ドメイン領域は壁位置から自動生成する。
4. 左端・右端はそれぞれ `x_1 - Δx/2`, `x_N + Δx/2` まで延ばす。

したがって、ドメイン背景、壁、bond 変数、ラベル位置は同じスピン配列から導出する。見た目だけで座標を別途決めない。

## 6. 凡例・注釈

凡例の完全透明背景は使わない。

優先順位:

1. 少数曲線では直接ラベル。
2. 必要なら半透明 paper 凡例。
3. 密な図では図外凡例。

文字色は theme-aware ink とし、黒固定にしない。凡例背景は light mode では paper を約 90% 不透明、dark mode では暗色 paper を約 85% 不透明とする。

## 7. 品質チェック

図を生成したら最低限次を確認する。

- ドメイン境界とスピン符号変化が一致しているか。
- 同一スピン配列を比較するパネルで壁位置が一致しているか。
- 文字が背景・線・曲線に埋もれていないか。
- 色に意味があり、装飾目的の色が増えていないか。
- 図だけ見ても主メッセージが1つ読み取れるか。
